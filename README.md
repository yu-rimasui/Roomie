# Roomie

「離れていても、同じ家に帰れる。」ふたりが自宅と小さな街で過ごす3DブラウザゲームのMVPです。

## 起動

Node.js 22以上を使います。

```sh
npm ci
npm run dev
```

表示されたローカルURL（通常 http://127.0.0.1:5173）を開いてください。環境変数なしで、ひとりで探索したり、同じブラウザの2タブで通信を検証したりできます。

```sh
npm test       # 移動・衝突・遷移・通信入力の9件
npm run build # TypeScript検査と本番ビルド
npm run preview
```

## 操作

- **WASD／矢印キー**：移動。見下ろしはワールドの4方向、一人称では向いている方向を基準に前後・横移動。
- **V**：見下ろし／一人称。両方とも同じシーン・プレイヤー座標を使います。
- **Q／E**：左右へ90度回転。一人称では画面右下のボタンでも回転できます。
- **エリア移動**：Homeの手前中央にある緑の玄関マットから外へ歩くとTownへ。Townの緑の屋根の自宅正面へ歩くとHomeへ。
- **ふたりで遊ぶ**：ルームの作成・招待での参加・退出。
- **Esc**：ダイアログを閉じる。入力中・ダイアログ表示中・ウィンドウが非アクティブのときは移動入力を解除します。

## ローカル通信の検証

1. 「ふたりで遊ぶ」→「ふたりのルームをつくる」。
2. 招待リンクを、**同じブラウザ・プロファイルの別タブ**で開きます。
3. 2タブ目で「ルームに参加する」→「世界にもどる」。
4. 片方を動かすと、もう片方にも相手の移動が表示されます。
5. 片方だけTownへ出ると相手の表示が消え、同じエリアに戻ると再表示されます。
6. 3タブ目の参加は拒否されます。タブを閉じた場合は約8秒で退室表示になります。

BroadcastChannelで2クライアント間の通信を行い、Web Locksで参加枠を直列化します。画面に「ローカル接続」「LOCAL PREVIEW」と明示します。**これはインターネット越しのオンライン接続ではありません。** 別端末・別ブラウザ・シークレットウィンドウ同士は通信できません。localhostまたはHTTPSが必要です。バックグラウンドタブの大幅なタイマー制限により期限切れになる場合は、ルームから退出して参加し直してください。

## Supabaseで遠隔通信を有効にする

外部サービスの作成・設定・公開は自動実行しません。以下の設定を済ませると、新しいルームはオンライン用になります。

1. Supabaseプロジェクトを用意します。
2. Authenticationで **Anonymous Sign-Ins** を有効にします。独自認証は実装していません。
3. SQL Editorで [`supabase/schema.sql`](supabase/schema.sql) を**一度だけ**実行します。既存の同名テーブルがある場合は内容を確認してください。
4. Realtimeの公開チャンネルを無効にし、非公開チャンネルを使用する設定にします。
5. `.env.example` を参考に `.env.local` を作り、以下を設定して開発サーバーを再起動します。

```dotenv
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

これらはブラウザに配信される公開用の設定値です。**service_roleキーや秘密鍵を設定しないでください。** 設定がない場合だけローカルモードを使います。オンライン接続が失敗したとき、ローカルへ黙って切り替えません。

### オンラインの権限制御

- Supabase匿名認証により利用者を識別。セッションはタブのsessionStorageに保存します。
- 作成・参加はSQL RPC経由。192bitのランダムな招待トークンを作り、DBにはSHA-256ハッシュだけを保存します。招待はURLのフラグメントに入れます。
- `join_room` はルーム行をロックし、最大2名をDBの一意制約と合わせて保証します。
- メンバーの作成・slot変更・他人の移動はクライアントに許可しません。RLSにより同じルームの座標だけを読めます。
- 移動座標を最大10HzでDBに更新し、Postgres Changesで配信します。Presenceはメンバー限定の非公開チャンネルで在室・切断を反映します。
- 招待リンクは参加権限を持つリンクです。パートナーだけに共有してください。
- オンラインでは**最初の2人の席を保持**します。切断や退出で第三者に席を開放しません。同じ認証セッションなら再参加できます。匿名セッションを失った場合は新しいルームを作ってください。

遠隔で遊ぶ際は、同じデプロイ先URLを使います。Viteの本番出力は `dist/`、ビルドコマンドは `npm run build` です。環境変数をホスティング先にも設定してください。公開・pushは今回行っていません。

## 構成

今回の作業先 `roomie_v2` は空で、既存コード・Gitリポジトリはありませんでした。隣の旧 `Roomie` はNext.js／Phaser構成ですが、変更していません。

Next.jsのサーバー機能が不要なため、React＋TypeScript＋ViteにThree.jsを直接組み合わせています。二視点は同じワールドのカメラのみを切り替え、独自ゲームサーバーや汎用エンジンは作っていません。

| ファイル                       | 責務                                                                   |
| ------------------------------ | ---------------------------------------------------------------------- |
| `src/App.tsx`, `src/style.css` | ゲーム画面、招待、接続状態、操作ガイド                                 |
| `src/game/world.ts`            | 固定マップ定義、プレイヤー座標、衝突・移動・エリア遷移、通信データ検証 |
| `src/game/scene.ts`            | 独自の3Dオブジェクト、室内・街・アバター描画                           |
| `src/game/Game.tsx`            | キー入力、フレーム更新、カメラ制御、相手の補間、描画ライフサイクル     |
| `src/network/room.ts`          | ローカル通信、Supabase認証・位置同期・Presence                         |
| `supabase/schema.sql`          | 2名制限、招待参加、RLS、Realtime権限                                   |
| `tests/world.test.ts`          | 物理・遷移・不正入力・接続期限の単体チェック                           |
| `tests/browser-check.js`       | Playwright CLIで実行する2タブの統合チェック                            |

すべてのキャラクター・建物・家具はコードで作成した独自形状です。参考画像や既存ゲームの素材は使用していません。外部画像・外部フォントは不要です。

## 検証

- `npm test`：9件。
- `npm run build`：TypeScript検査・本番ビルド。
- ブラウザ統合チェック：同一ブラウザの独立した2ページで、双方の移動・V切り替え時の座標維持・Home/Townの別行動と再合流・3人目拒否・タブ終了後の切断を検証します。

Playwright CLIが利用できる環境では、開発サーバーとブラウザを起動して次を実行できます。

```sh
playwright-cli open http://127.0.0.1:5173 --headed
playwright-cli run-code --filename tests/browser-check.js
```

**Supabaseプロジェクト未設定のため、オンラインRPC・RLS・別端末での通信は未検証です。** ローカル検証をオンライン接続の成功とは扱っていません。SQLを適用したうえで、別の2ブラウザ・認証セッションから上記の同じシナリオを確認する必要があります。

## 今回の範囲と制限

Home／Town、固定家具、区別できる2人のアバター、滑らかな移動、基本的な衝突、二視点、招待ルーム、位置補間を実装しています。壁は見下ろしで室内を見やすくするためカットアウェイ表現です。装飾用の建物には入れません。

NPC、クエスト、アイテム、家具編集、スマートフォン専用操作、360度マウス視点、音声・動画通話は実装していません。ゲームはデスクトップのキーボード操作が前提です。描画にはWebGLが必要です。Three.jsを含むため、本番バンドルは約1MB（gzip約260KB）です。初期版ではワールドを一括読み込みしています。
